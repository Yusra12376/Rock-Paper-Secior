# Rock Paper Scissors

A simple browser-based rock-paper-scissors game built with HTML, CSS, and JavaScript. Choose a move, play against the computer, and keep track of each side's score.

## Features

- Play Rock, Paper, or Secior (the app's spelling of scissors) against a computer choice.
- See whether each round is a win, loss, or draw.
- Track player and computer scores.
- Use **Play Again** to reset the scores and start over.

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Yusra12376/Rock-Paper-Secior.git
   cd Rock-Paper-Secior
   ```

2. Open `index rock.html` in a modern web browser. The HTML, CSS, and JavaScript files should remain in the same folder. No package installation or build step is required.

## Project files

- `index rock.html` — game page and move/score elements.
- `paper.css` — page layout and styling.
- `seccior.js` — computer choice, round result, score tracking, and reset behavior.

## Image assets

The HTML references `rock.png`, `paper.png`, and `secior.png` in the project folder. Those image files are not currently present in the repository root, so add them there (or update the image paths) for the move illustrations to appear.
